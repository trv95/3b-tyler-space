Receives authenticated `POST /ip-enrichment-submit` requests from the enrichment form. It validates that the submitted address is a public IPv4 or IPv6 address, retrieves its report from VirusTotal at `GET https://www.virustotal.com/api/v3/ip_addresses/{ip}`, and posts a compact summary to Slack using `POST https://slack.com/api/chat.postMessage`.

Input is JSON with an `ip` string. Output is an HTTP JSON response containing the IP, determination, selected VirusTotal attributes, analysis counts, report URL, enrichment time, and Slack delivery metadata. Every successful enrichment is sent to `#3b-demo` (`C0BKQMP3LSU`) and persisted as an independent history record after Slack confirms delivery.
