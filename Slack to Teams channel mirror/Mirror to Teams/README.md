Posts a Slack message into the Teams channel via `POST /teams/{team}/channels/{channel}/messages` (or `/messages/{id}/replies` for a thread reply, resolved through `thread_map`). Looks up the author with `users.info`, converts Slack mrkdwn to HTML, and records the new Teams message id so it is not mirrored back. Reads and writes `mirror.sqlite` on the `mirror_state` volume. Connectors: Tyler Slack, Tyler Microsoft Teams.
