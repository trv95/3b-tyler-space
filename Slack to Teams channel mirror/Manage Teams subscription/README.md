Cron step (every 20 minutes) that keeps the Graph change-notification subscription for the Teams channel alive: renews the stored subscription id via `PATCH /subscriptions/{id}`, or creates a new one pointing at the `/teams-notifications` route. The subscription id lives in the `settings` table of `mirror.sqlite` on the `mirror_state` volume. Creation fails until the workflow is published, because Graph must validate the live route. Connector: Tyler Microsoft Teams.
