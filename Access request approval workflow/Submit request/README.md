API endpoint at `/access-request-submit`. Receives the form JSON, creates a Tines case in the **Demo** team (`19060`) via the Cases API (`POST /api/v2/cases/`), then posts an interactive approval message to Slack `#3b-notifications` (`chat.postMessage`) with Approve / Deny buttons. Each button carries the case id and request summary so the [Approval action](<../Approval action/script.ts>) step can act on it. Returns `{ ok, case_id, case_url }`.
